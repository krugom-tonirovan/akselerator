# Проверка метеоданных Элисты

## Исходные файлы

В проекте используются две пользовательские выгрузки станции Элиста, WMO 34861:

- `Элиста meteo.ru.xlsx`: лист `Лист1`, 43 832 срока наблюдений за 2010–2024 годы, шаг 3 часа. В книге есть заголовок и 15 столбцов.
- `34861.01.01.2010.31.12.2024.1.0.0.ru.ansi.00000000 rp5.ru.csv`: выгрузка RP5 в кодировке CP1251, 42 810 сроков; в заголовке указаны температура, относительная влажность, ветер, видимость и осадки.

Строки сопоставляются по дате и часу: дате наблюдения из полей `Год`, `Месяц Грин`, `День Грин`, `Срок Грин` meteo.ru соответствует поле `Местное время в Элисте` RP5. Все сроки RP5 имеют запись meteo.ru; у meteo.ru остаётся 1 022 срока без соответствующей записи RP5, преимущественно в начале января 2010 года.

## Разметка пыльных бурь

Целевой признак берётся из столбца `Погода в срок`. По настройке проекта положительный класс — только коды 30–35. Код 9 не включён. В исходной таблице 82 положительных срока:

| Код | Число сроков |
| --- | ---: |
| 30 | 7 |
| 31 | 52 |
| 32 | 20 |
| 33 | 1 |
| 34 | 1 |
| 35 | 1 |

Код `Погода между сроками` не используется как целевой столбец. Одна запись с кодом вне допустимого диапазона 00–99 исключается. Разметка соответствует таблице SYNOP 4677 для пыльных/песчаных бурь; описание кодов: [WMO Code Table 4677](https://www.nodc.noaa.gov/archive/arc0021/0002199/1.1/data/0-data/HTML/WMO-CODE/WMO4677.HTM).

## Признаки модели и очистка

Для обучающей выборки взяты 42 684 срока, где есть целевая метка и основные погодные признаки. Из RP5 используются температура `T`, влажность `U` и видимость `VV`; из meteo.ru — направление и скорость ветра, включая максимальную скорость. Порыв формируется как максимум из скорости и доступных максимумов ветра RP5/meteo.ru. Видимость из диапазонов менее 1 км переводится из метров в километры; 300 пустых значений заменяются на 10 км — наиболее частое значение в выгрузке.

Ветер преобразуется в восточную и северную составляющие. Месяц задаётся парой синус/косинус, чтобы декабрь и январь были близкими значениями. Осадки не включены в модель: в RP5 они отсутствуют в 78 из 82 положительных сроков, поэтому признак мог бы отражать пропуски отчётности, а не условия пыльной бури. Код текущей погоды RP5 не используется в признаках, чтобы не дублировать целевую метку.

Суховеи отдельной меткой не представлены и этой моделью не распознаются.

## Воспроизводимость

Скрипт `tools/train_elista.py` проверяет заголовки meteo.ru, формирует совпавшие сроки, считает метрики на временном отложенном периоде 2022–2024, затем обучает итоговый лес на всей выборке и экспортирует его в `model/elista_forest.json`. Схема модели и порядок признаков задаются скриптом; для изменений состава столбцов нужно обновить аудит и повторно оценить качество.
