# Методика цифрового двойника

## Назначение

Веб-прототип позволяет очертить поле и рассчитать варианты защитных лесополос без ручного ввода погодных условий. По умолчанию используется типичный архивный сценарий, составленный по наблюдавшимся пыльным бурям на метеостанции Элиста. Это сценарный инструмент для дипломной работы, а не оперативная система предупреждения.

## Обучение модели

Целевой класс — коды 30–35 в поле `Погода в срок` выгрузки meteo.ru. Код 9 по прямому указанию пользователя исключён. Всего в данных 82 положительных срока из 42 684 строк после временного сопоставления с RP5 и очистки основных признаков.

Random Forest использует температуру, относительную влажность, скорость ветра, порыв, восточную и северную составляющие ветра, видимость и месяц (циклическое кодирование). Признаки собраны из двух выгрузок: температура/влажность/видимость — RP5; направление/скорость/максимальная скорость и целевые коды — meteo.ru. Осадки исключены из-за отсутствия данных на 78 из 82 положительных сроков.

Оценка качества сделана временным разделением: обучение на 2010–2021 годах, проверка на 2022–2024 годах. На отложенном отрезке: 8 748 строк, 24 положительных срока, средняя точность Average Precision — 0,496, ROC-AUC — 0,995. При условном пороге индекса 0,5 полнота составляет 0,75, точность — 0,212. Положительные сроки группируются в эпизоды бурь, поэтому их нельзя считать 24 независимыми событиями. Из-за малого числа эпизодов метрики предварительные.

Для обучения используется `RandomForestClassifier` из scikit-learn: 400 деревьев, максимальная глубина 8, минимум 4 наблюдения в листе, `class_weight=balanced_subsample`, `random_state=42`. После оценки на отложенном периоде итоговый лес переобучается на всех доступных годах. Его дерево экспортируется в JSON; локальный сервер исполняет деревья без scikit-learn.

Счёт модели не калиброван как вероятность. Число в интерфейсе — относительный индекс для сравнения вариантов при заданном сценарии.

## Расстановка лесополос

Автоматический сценарий использует сводные погодные условия 82 эпизодов пыльных бурь на станции Элиста за 2010–2024 годы. При выборе лесополос учитываются частоты всех размеченных направлений: юго-восток — 59 эпизодов, восток — 18, юг — 3, запад — 2. Это историческое распределение, а не прогноз для конкретной даты.

Для каждого архивного направления определяется внешняя, наветренная сторона контура и строится отрезок посадки вдоль неё. Отрезок вынесен на 10 м за границу поля, чтобы не занимать пашню. На сетке внутри участка оценивается защита от каждого направления, затем отдельно сравниваются варианты с 1, 2 и 3 отрезками. Веса направлений пропорциональны числу эпизодов в архиве.

Для каждой точки учитывается ближайшая пересекающая линию ветрового потока полоса в пределах `20H`, где `H` — высота насаждения. Принята упрощённая параметризация отношения скорости ветра после полосы к фоновой:

`r(d,H,p) = p + (1 − p) · (1 − exp(−0.15 · d/H))`, при `0 ≤ d ≤ 20H`.

Здесь `d` — расстояние за полосой, `p` — доля потока у кромки. Сценарий для каждой точки пересчитывается с уменьшенными скоростью и порывами ветра, затем варианты ранжируются по взвешенному среднему индексу Random Forest. По умолчанию предлагается наименьшее число полос, индекс которого не более чем на 5 пунктов из 100 выше лучшего проверенного варианта. Допуск в 5 пунктов — проектное правило для экономии посадочной длины, а не установленный агрономический норматив.

Схема показывает отрезки за наветренной частью периметра, а не замкнутое кольцо. Полное кольцо может быть полезно для защиты от ветра со всех сторон, но требует отдельного расчёта затрат, геометрии внешней полосы и прав на землю. Прототип не проверяет кадастровые границы, дороги и ограничения на посадку; эти условия нужно уточнить до проектирования.

## Как учтена методика лесоразведения

В статье Д. К. Сучкова о полезащитных полосах в сухостепной и полупустынной зонах указано, что при проектировании следует учитывать тип местности; для степных районов приведён ориентир около 200 м между полосами. В статье также рассматриваются подготовка почвы, посадочный материал и мелиорация. Этот материал используется как основание для отдельной проверки пригодности места посадки, но не как обучающая выборка погодного Random Forest.

Ориентир 200 м относится к размещению полос в системе сельскохозяйственных полей. Его нельзя напрямую применять как обязательный интервал для внешних отрезков, которые прототип предлагает вдоль границы одного участка. До получения агрономических данных он остаётся справочной проектной подсказкой, а не жёстким ограничением.

## Рельеф и пригодность места посадки

Карта уклонов нужна для пространственной части цифрового двойника, но не для текущего погодного классификатора. Random Forest обучен на наблюдениях одной метеостанции и не имеет размеченных примеров для обучения по уклону. Добавление высоты или уклона в этот классификатор без соответствующих обучающих данных создало бы видимость точности, не улучшая обоснованность прогноза.

Уклон следует подключать отдельным ГИС-слоем пригодности вместе с экспозицией склона и направлением поверхностного стока. Он поможет выявлять участки, где линию посадки следует проверять по горизонталям и противоэрозионной схеме. Для первичного обзора можно получить производные уклона из цифровой модели рельефа; для проектирования на конкретном поле нужна достаточно подробная и проверенная съёмка, поскольку грубая глобальная сетка не описывает микрорельеф.

Для содержательной оценки посадки нужны также локальные сведения о почве: тип и механический состав, засолённость, эрозионное состояние, глубина и минерализация грунтовых вод. Статья Сучкова подтверждает роль подготовки почвы и посадочного материала, но не даёт оснований автоматически вывести эти свойства только по контуру поля. Пока эти слои и обследования не подключены, приложение рассчитывает ветровой сценарий, а не подтверждённую агрономическую пригодность.

## Ограничения

- 82 положительных срока за 15 лет — небольшой и эпизодически сгруппированный набор. Временная проверка имеет только 24 положительных срока.
- Одна станция не описывает пространственное поле пыли по всей Калмыкии; результат за пределами района станции — экстраполяция.
- Отдельной разметки суховеев нет, поэтому модель оценивает только коды пыльных/песчаных бурь.
- Пока не подключены уклон, экспозиция и сток, существующие насаждения, свойства почвы и грунтовых вод, сельхозтехника, кадастровые ограничения, породный состав и выживаемость саженцев.
- Расстояние около 200 м из методики для степных систем полос не проверяется автоматически: текущая схема сравнивает внешние отрезки вокруг одного участка.
- Перед прикладным использованием нужны независимые наблюдения, спутниковые данные, сведения о почвах и полевая проверка аэродинамического профиля.
