# ПОЛЕ · ЛЕС

Геопространственный цифровой двойник защитных лесополос для дипломного проекта. Пилотная область — Элиста, Республика Калмыкия. На карте можно обвести участок и получить сравнение вариантов внешних лесополос по историческому сценарию пыльных бурь.

## Стек

- **FastAPI** — API и запуск модели на Python.
- **React + Vite** — клиентское приложение и сборка JavaScript.
- Расчёт Random Forest читает экспорт модели из `model/elista_forest.json`; сторонний `joblib` не используется.

Интерфейс и картографические действия сохранены. На этапе миграции React подключает существующий контроллер карты как модуль; так API и сборка уже работают на фреймворках, а логику рисования карты можно переносить в React-компоненты постепенно.

## Первый запуск

Нужны Python 3.10+ и Node.js 20.19+ или 22.12+.

1. Установите Python-зависимости из корня проекта:

   ```powershell
   python -m pip install -r requirements.txt
   ```

2. Установите JavaScript-зависимости:

   ```powershell
   cd frontend
   npm.cmd install
   cd ..
   ```

3. Запустите `run.bat`. Он поднимет API на порту `8000` и Vite на порту `5173`.
4. Откройте `http://127.0.0.1:5173`. Для доступа с другого устройства в той же сети используйте локальный IP компьютера и порт `5173`.

API доступно по адресу `http://127.0.0.1:8000`; проверка состояния модели: `/api/health`. Vite перенаправляет запросы `/api` в FastAPI.

## Сборка для запуска одним сервером

```powershell
cd frontend
npm.cmd run build
cd ..
python server.py
```

FastAPI отдаёт собранный интерфейс по `http://127.0.0.1:8000`. Сборка создаётся в `frontend/dist` и не хранится в исходниках.

## Данные и модель Элисты

Для обучения используются выгрузки meteo.ru и RP5 по станции Элиста, ВМО 34861, за 2010–2024 годы. Пыльные бури размечены кодами 30–35 в `meteo.ru`; отдельной разметки суховеев нет, поэтому модель их не распознаёт. Подробности подготовки данных и ограничений расчёта находятся в [аудите данных](docs/DATA_AUDIT.md) и [методике](docs/METHODS.md).

Переобучение модели выполняется отдельно:

```powershell
python -m pip install -r requirements-training.txt
python tools/train_elista.py
```

## Важно о результатах

Модель формирует относительный сценарный индекс, а не вероятность события и не прогноз погоды. Схема внешних лесополос основывается на упрощённом аэродинамическом профиле. Уклоны, почвы, доступность земли за границами участка, дороги и права на посадку не проверяются. Перед практической посадкой нужно обследовать территорию и проверить ограничения.

Картографические подложки OpenStreetMap и Esri загружаются через интернет. API и расчёт работают локально независимо от подложки.
